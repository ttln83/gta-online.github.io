🎮 Questions Débutant

Par où commencer dans GTA Online ?

+

Ordre recommandé :

  1. Tutoriel avec Lamar
  2. Missions contact → 500K
  3. Kosatka (2.2M) - priorité #1
  4. Grind Cayo Perico

Moyen le plus rapide de gagner de l'argent ?

+

Cayo Perico Heist : 1.5-1.9M en 60-90min
Combo optimal : Bunker + Cayo + Contrats = 2-3M/jour

Comment éviter les griefers ?

+

Session publique solo :

  • PC : Firewall ou Task Manager suspend 10sec
  • Xbox : Test NAT type
  • PS4/PS5 : MTU 800

🏢 Questions Business

Comment optimiser Cayo Perico ?

+

Route optimale (12-15min) :

  1. Approche Kosatka + Drainage Tunnel
  2. 2× Cocaïne + Cible primaire
  3. Sortie Main Gate → Nage 200m

⚡ Hard Mode : +10% payout (relancer dans 48min)

Bunker : acheter ou voler supplies ?

+

TOUJOURS ACHETER !
Acheter 75K = 135K profit en 2h30
Voler = 90min perdues → Faites un Cayo à la place (1.5M)
