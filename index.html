Pro Tips

Les secrets des meilleurs joueurs

💸

Maximiser les profits

La méthode optimale:

  1. Lancer production Nightclub + Bunker
  2. Faire 1-2 Cayo Perico (3h)
  3. Alterner avec contrats Agence
  4. Vendre Nightclub/Bunker en session publique bonus

💰 Résultat: 5-7M par session de jeu

🥷

Cayo Perico Solo

Route optimisée:

  • ✅ Entrée: Drainage Tunnel
  • ✅ Objectif secondaire: 2 cocaïnes dans compound
  • ✅ Sortie: Main Gate (moto)
  • ✅ Temps record: ~12 minutes

⏱️ Optimisé = Plus de runs par heure

⚔️

Survivre aux Griefers

Techniques défensives:

  • 🛡️ Ghost Organization (12k, 3min invisibilité)
  • 🚁 Utiliser Sparrow/Oppressor pour mobilité
  • 🏢 Se téléporter au bureau/appartement
  • ⚡ Mode passif pour livraisons solo

🎯 Protection = Profits sécurisés

📈

Ordre d'investissement

Priorités par budget:

  1. 2.2M → Kosatka (débloquer Cayo Perico)
  2. 2M → Agence (contrats VIP réguliers)
  3. 3M → Oppressor Mk II (mobilité x10)
  4. 2.8M → Nightclub + upgrades (passif)
